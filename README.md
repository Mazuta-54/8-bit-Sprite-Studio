## О проекте

**8-bit Sprite Studio** — это десктопное приложение для создания пиксель-арта и 2D-анимации, ориентированное на начинающих инди-разработчиков и студентов, изучающих геймдизайн.

### Проблема, которую решает проект

Существующие универсальные редакторы (Photoshop, GIMP) перегружены функционалом и не имеют нативной привязки к сетке пикселей. Специализированные инструменты (Aseprite) являются платными. **8-bit Sprite Studio** объединяет простоту Piskel с производительностью десктопного приложения, добавляя гибкую настройку сетки и экспорта, оставаясь при этом **бесплатным ПО с открытым исходным кодом**.

### Целевая аудитория

- Студенты направлений «Программная инженерия» и «Геймдизайн».
- Инди-разработчики, создающие проекты в ретро-стилистике.

### Ценность проекта

- **Образовательная:** изучение графических API, алгоритмов обработки изображений, архитектуры десктопных приложений.
- **Практическая:** рабочий инструмент, упрощающий пайплайн подготовки ассетов для Unity, Godot и других движков.

## ✨ Возможности

### Инструменты рисования

- ✏️ **Карандаш** — основной инструмент для рисования пикселей.
- ✖️ **Ластик** — стирает пиксели (возвращает к прозрачности).
- ☕ **Заливка (Bucket)** — заливает замкнутые области (алгоритм BFS).
- ⚱️ **Пипетка (Eyedropper)** — берёт цвет с холста.
- **Настраиваемый размер кисти** (1–10 px).

### Работа с анимацией

- 🎞️ **Таймлайн** с миниатюрами кадров.
- ➕ **Добавление, дублирование и удаление кадров**.
- ⏯️ **Воспроизведение анимации** с настраиваемой длительностью каждого кадра (в мс).
- **Предпросмотр** текущего кадра в реальном времени.

### Холст и навигация

- **Настраиваемая сетка пикселей** с возможностью привязки (Snap to Grid).
- **Масштабирование** от 50% до 800% (колёсико мыши или меню «Вид»).
- **Строка состояния** с координатами курсора, текущим цветом и размером холста.

### История и безопасность

- ↩️ **Undo/Redo** (Ctrl+Z / Ctrl+Y) — стек истории до 50 состояний.
- **Сохранение проекта** — экспорт в PNG и Sprite Sheet с масштабом 1x–8x.

### Экспорт

- **PNG** — одиночный кадр или текущий спрайт.
- **Sprite Sheet** — все кадры в едином изображении для игровых движков.
- ⚙️ **Диалог экспорта** с настройками имени, формата и масштаба.

## Архитектура

Проект построен на **многослойной архитектуре (Layered Architecture)** с использованием паттернов **MVC** и **Command**.

┌─────────────────────────────────────────────────────────┐
│ PRESENTATION LAYER │
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────────┐ │
│ │ MainWindow │ │ Dialogs │ │ Status Bar │ │
│ └─────────────┘ └─────────────┘ └─────────────────┘ │
└──────────────────────────┬──────────────────────────────┘
│
┌──────────────────────────▼──────────────────────────────┐
│ BUSINESS LAYER │
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────────┐ │
│ │ SpriteModel │ │ ToolManager│ │ HistoryManager │ │
│ │ (Model) │ │ (Strategy) │ │ (Command) │ │
│ └─────────────┘ └─────────────┘ └─────────────────┘ │
└──────────────────────────┬──────────────────────────────┘
│
┌──────────────────────────▼──────────────────────────────┐
│ DATA LAYER │
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────────┐ │
│ │ DatabaseMgr │ │ FileExporter│ │ JSON Serializer│ │
│ └─────────────┘ └─────────────┘ └─────────────────┘ │
└─────────────────────────────────────────────────────────┘


### Паттерны проектирования

- **MVC** — разделение состояния холста (Model), визуализации (View) и обработки действий (Controller).
- **Command** — реализация Undo/Redo: каждое действие рисования инкапсулируется в объект-команду.
- **Strategy** — реализация различных инструментов рисования (Карандаш, Ластик, Заливка, Пипетка).

### Модель данных (согласно ER-диаграмме из ТЗ)

| Сущность | Назначение | Связи |
|----------|-----------|-------|
| `USER` | Локальный профиль пользователя | 1:N с `PROJECT` |
| `PROJECT` | Основная сущность с холстом и FPS | 1:N с `FRAME`, `PALETTE`, `SPRITESHEET` |
| `FRAME` | Один кадр анимации | 1:1 (логическая) с `PIXEL_DATA` |
| `PALETTE` | Набор цветов проекта (`colors_json`) | — |
| `SPRITESHEET` | Результат экспорта (`file_path`, `format`, `metadata_json`) | — |

> **Обоснование:** пиксели хранятся в поле `pixel_data_json` (например, `{"0,0": 1, "0,1": 5, ...}`) вместо отдельной таблицы `PIXEL`, что позволяет загружать кадр одной операцией и избежать падения производительности.

## Установка и запуск

### Требования

- Python 3.11+
- Tkinter (входит в стандартную поставку Python)

### Клонирование репозитория

```bash
git clone https://github.com/username/8-bit-sprite-studio.git
cd 8-bit-sprite-studio

Запуск:

python sprite_studio.py 
или
8 Bit Sprite Studio.exe

Использование:
Создание нового проекта
Запустите приложение — откроется диалог «Новый проект».

Укажите имя, ширину и высоту (от 8 до 512 px), выберите цвет фона.

Нажмите «Создать».

Рисование:
Выберите инструмент на левой панели (или нажмите горячую клавишу).

Выберите цвет в палитре справа (или добавьте свой через «+ Свой цвет»).

Рисуйте на холсте левой кнопкой мыши. Для заливки — кликните в замкнутую область.

Работа с анимацией:
Нажмите «+ Кадр» в таймлайне, чтобы добавить новый кадр.

Используйте «Дублировать кадр» для копирования текущего кадра.

Настройте длительность кадра (в мс) на левой панели.

Нажмите ▶ для воспроизведения анимации.

Экспорт:
Меню «Файл» → «Экспорт...».

Укажите имя файла, формат (PNG или Sprite Sheet) и масштаб (1x–8x).

Нажмите «Экспортировать» — файл сохранится в текущей директории.

Горячие клавиши:
Клавиша:	     Действие:
B	             Карандаш (Pencil)
E	             Ластик (Eraser)

Ctrl + Z	     Отменить (Undo)

Колёсико мыши	 Масштаб холста
